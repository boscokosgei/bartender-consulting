# 🍸 Shake & Stir — Bartender Consulting

A MERN stack web application for a bartender consulting service, containerized with Docker.

## Features

- **Solutions page** — Consulting services offered (menu development, staff training, bar operations, beverage programs)
- **Services page** — Rentable bartending services with pricing and booking modal

## Tech Stack

- **M**ongoDB 7 — Database
- **E**xpress — REST API
- **R**eact 18 — Frontend SPA with React Router
- **N**ode.js 18 — Server runtime
- **Docker + Compose** — Containerization
- **Nginx** — Reverse proxy for the client
